🧮 Calculator Web App

This is a simple calculator application that performs basic arithmetic operations such as addition, subtraction, multiplication, and division. The project is built for learning basic programming concepts.

## Technologies Used
  - HTML
  - CSS
  - JavaScript

✨ Features

  - ➕ Addition
  - ➖ Subtraction
  - ✖️ Multiplication
  - ➗ Division
  - 🧹 Clear / Reset functionality
  - 📱 Responsive design
  -⚡ Fast and lightweight

📂 Project Structure

    │── Calculator.html # Main HTML file
    │── style.css # Styling (CSS)
    │── script.js # Calculator logic (JavaScript)
    │── README.md # Project documentation

This is a modern and user-friendly calculator interface designed with a clean dark theme and smooth rounded components. The calculator features a large, easy-to-read display at the top for showing inputs and results.

The buttons are well-spaced and color-coded for better usability:

  - Red button for clear (C)
  - Orange buttons for arithmetic operations (+, −, ×, ÷)
  - Purple button for equals (=)
  - Dark gray buttons for numbers and decimal input

📦 How to Run the Project Locally

Clone the repository

    git clone https://github.com/PavanPochi06/Calculator.git

Navigate to the project folder

    cd Calculator

Open Calculator.html in your browser

    open calculator.html
